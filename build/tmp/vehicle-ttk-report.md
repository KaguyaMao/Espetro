## 3. 结论与异常点

1. **主战坦克对步战是碾压**：2 发 / 5.5–6s，而步战用机炮要 74 发 / 13.3s（还须全程命中）。
2. **04A 的反坦克答案是炮射导弹**：打主战 3 发 / 11.0s，比 HE 的 10 发 / 49.5s、机炮的 74 发 / 13.3s 都好；但**打步战时 HE（4 发 / 16.5s）不如导弹（2 发 / 5.5s），更不如自己 30mm（8.4s）**。
3. **主战坦克的炮射导弹没用**：ZTZ-99A 的 650 导弹对坦克单发 163.8（>AP 的 150），但都要 4 发，对步战则从 2 发变 3 发（打 ZBD-04A）→ 带导弹只会更差，属于纯粹的多余弹种。
4. **反坦克导弹明显超模**：ZBL-08/M3A3 的 1500 导弹 **1 发即毁任何步战**（M3A3 400 血刚好被 401.5 秒杀），**2 发秒任何主战坦克**且双联弹匣 1.5–2s 打完。步战对坦克的真实威胁是导弹，不是主炮/机炮。
5. **机炮刮坦克在数值上可行**：30mm 74 发 / 13.3s 就能拆 550 血主战坦克，比坦克互毁的 18s 还快 —— 只靠命中率和掩体兜底，抗性层面缺少对机炮的额外减伤。
6. **M3A3 的 25mm 最弱**（200 RPM、85 伤害、×0.1 → 8.5/发，打坦克 19.2s），全靠陶式导弹撑场面；BTR-82A 的 30mm（65）比 ZBL-08（75）弱约 14%。
7. 美国轮式步战 **M1126 只有一挺 12 伤害机枪**（`gunfire` 走 `All×0.2 × #projectile×0.1` → 单发 0.24），对装甲毫无威胁，故未列入矩阵。

## 4. 模型依据（反编译确认）

| 环节 | 事实 |
|---|---|
| 直接命中入口 | `FastThrowableProjectile.performDamage(entity, damage, headshot)` → `forceHurt(target, ModDamageTypes.causeProjectileHitDamage(...), damage × 系数)` |
| 命中伤害类型 | `superbwarfare:projectile_hit` |
| directEntity | 炮弹实体：`cannon_shell` / `small_cannon_shell` / `wire_guide_missile` |
| 抗性结算 | `VehicleEntity.hurt` → `DamageModifier.compute` → 先扣命中**部件**，再 `super.hurt` 扣**车体**血量 |
| 条目语义 | `DamageModify.compute`：`IMMUNITY→0`、`REDUCE('+'/'-')→max(amount−value,0)`、`MULTIPLY('*')→amount×value`，按 JSON 列表顺序逐条应用 |
| 爆炸部分 | 命中后另触发 `buildExplosion()`，用 `ExplosionDamage`（100mm 为 30、120mm 为 5）× `custom_explosion` 抗性 → 量级很小，未计入矩阵 |
| 判定 | 打爆车体即摧毁；炮塔/轮/引擎独立血量（坦克炮塔 150、步战 100、轮 40、引擎 60），打空只致残不击毁 |

**未计入**：飞行时间、跳弹/未命中、入射角、部件损坏的附加影响、维修补给、乘员操作差异。
