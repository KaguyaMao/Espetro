# Stupid Tactics Minecraft — Logo v1

设计日期：2026-11-09。

## 成品

- `stupid-tactics-main-transparent-v1.png`：主标，1536 × 1024，RGBA 透明 PNG。
- `stupid-tactics-st-avatar-v1.png`：同系列 ST 方形头像；保持生成原始分辨率。

主标题采用双行 STUPID / TACTICS；MINECRAFT 为独立副标题。
配色采用军白、信号黄和炭黑；黄色方块化装甲剪影呼应 Minecraft 的组合兵种玩法。
文字以大字重、方形端点和少量切口构成军事游戏字标风格。

本次使用内置 imagegen 工具生成并派生头像；完整提示词见 `prompts.md`。
主标已核对标题拼写和 PNG alpha；头像已核对方形尺寸和 ST 文字。
这些文件是品牌设计素材，尚未接入模组 UI 或服务器配置。
方形头像为高清素材，若配置 Minecraft 原生 server-icon.png，需要另行导出为其要求的尺寸。
