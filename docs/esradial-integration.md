仅处理1.20.1，已合入上游90e2980补交的FixedWeapon/VehicleInventoryGate源码。配套：Espetro1.1.3-l、EsPoints1.1.1e、EsRadial0.3.2、ApricityUI1.2.6。

# 时钟布局与分类轮盘（EsRadial 0.3.2）

默认按30°角度参考线安排真实按钮，不生成12个固定槽位。按钮仅图标，悬停名称与小号说明在中心；通用底部提示删除，返回是轮盘中的图标扇区，右键不导航。

## 主页

| 位置 | 功能 |
| --- | --- |
| 12-2点 | 队包获取 |
| 10-12点 | 电台建造 |
| 2-3点 | 黄色敌军标记入口 |
| 9-10点 | 黄色工事建造入口 |
| 3-9点 | 进攻、防守、移动、观察、请求接送，五项均分 |

请求弹药、请求建材从菜单移除，协议枚举序号保留。主页不再单列战术指令目录。身份或缺少模组导致功能不可用时，仍使用原服务端权限；电台、队包不向火力组长开放。

## 子目录

工事首页：12-3点功能性建筑、3-6点防御工事、6-9点武器、9-12点返回，四个90°扇区。功能性建筑是兵站、弹药箱、维修站，三项同样各占90°，服务器未开放的项目显示不可用原因。

其他建筑、敌军标记及子目录从12-1点顺时针每项30°，默认返回9-12点。空白仅留在最后一个选项和返回之间；九项时无空白，十/十一项使用返回区域并将返回缩到60°/30°，超过十一项继续分目录。

地图标点共用目录与角度规则，放置位置固定为打开时点击的地图坐标。地图根页只有可用于地图的敌军入口和五种战术标点，不在地图发送建造/队包指令。

## 自定义与接入

F6编辑；拖动图标扇区或空槽调顺序，拖动分界线调大小，滚轮旋转；Tab切换30°/45°混合、30°、45°、自由。Enter保存、Esc取消、R恢复默认后保存。客户端 `config/esradial/layouts.json` 下次打开重读。

已有自定义布局优先于默认布局；在该页用F6、R、Enter恢复新排版。中心名称使用ApricityUI平滑字体，圆环继续按真实像素密度绘制。

`.backSlot(callback)` 是导航槽，不在松开按键时触发；地图宿主使用自己的返回回调。显式扇区每个动作都需 `.sectorLast(start,sweep)`。`RadialCommandMenu` 保留贡献菜单角度，按稳定ID匹配各模组动作。
