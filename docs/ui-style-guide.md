# Espetro UI · 简约毛玻璃 · 2026-11-14

本版采用无边框半透明按钮、暖白文字和克制的平面层级。亮暗两套模式共用布局。去除科技感外框、切角、刻度、装饰网格、假终端编号和投影高光；阵营、警告和状态的语义颜色保留。

改版前的工作区 UI、客户端 FancyMenu 配置及原 jar 已完整备份，见 [本次交付记录](MINIMAL_GLASS_UI_2026-11-14.md)。旧版指南和核心源码另存于 `archive/end02-before-minimal-glass-2026-11-14/`。

## 使用

| 客户端指令 | 功能 |
| --- | --- |
| `/esui theme light` | 亮色毛玻璃 |
| `/esui theme dark` | 暗色毛玻璃，默认 |
| `/esui theme toggle` | 亮暗互换 |
| `/esui` 或 `/esui theme` | 当前主题与用法 |

无需 OP，仅影响自己的客户端，切换立即生效。主题保存在游戏实例的 `config/espetro-ui.properties`。带颜色的控件在主题版本变化后重建；不重新初始化页面，保留密码输入等已有状态。安装新 jar 需要重启客户端，此后的切换无需重启或 `/reload`。

## 令牌

`client/gui/UiTheme.java` 是唯一配色源。不要在其他类缓存动态色板或新增 ARGB 字面量。`setMode()` 更新令牌并递增 `revision()`；缓存必须跟随版本失效。

| 用途 | 暗色 | 亮色 |
| --- | --- | --- |
| 正文 `TEXT` | `#F0F2E8` | `#171A16` |
| 次级 `TEXT_SECOND` | `#C0C6B8` | `#4B5046` |
| 全屏底色 `FROST_SCRIM` | `#111410`，60% | `#EEEFE6`，70% |
| 卡片 `GLASS_PANEL` | `#111410`，65% | `#F4F4ED`，65% |
| 轻底托 `GLASS_PANEL_SOFT` | `#111410`，40% | `#F4F4ED`，40% |
| 按钮色 | 暖白 `#F0F2E8` | 深墨 `#20251F` |

按钮透明度为常态约 10%、悬停 30%、选中 25%、主操作 22%、禁用 4%。不画边框、悬停下划线或选中角标。焦点与选择通过底色区分，文字使用 `controlText()`，避免旧版反相文字在透明按钮上失去对比度。输入框保留原有输入行为，焦点同样用淡色底提示。分隔线仅用于实际的信息分组。

`glassSurface()` 将旧调用方的不透明填色转成玻璃底；`controlFill()` 限制按钮 alpha，保留必要的语义色。世界标记、阵营和危险提示继续表达原语义。对比度测试使用黑、白场景与半透明层实际合成后的颜色。

## 绘制顺序与 FancyMenu

FancyMenu **3.9.9 至 4.0 之前版本**声明为客户端必需前置，服务端不要求安装。测试实例已安装 Forge 1.20.1 的 FancyMenu 3.9.9。

`FancyMenuGlass` 通过受控反射调用其原生 `GuiBlurRenderer`。先刷新已有背景批次，再模糊，最后绘制文字和按钮；同时保存并恢复渲染状态。桥接将原版 pose 中的缩放、平移转换一次，使用 FancyMenu 的未缩放重载，避免重复缩放。API 不可用或着色器失败时记录一次并退化。详见 [API 核验](FANCYMENU_GLASS_BRIDGE_API_AUDIT_2026-11-14.md)。

`AuiScreen` 在内容滑入前绘制稳定的全屏模糊底。`beginScreen()/endScreen()` 必须成对，嵌套教学预览复用宿主底图，避免再次采样文字。`UiPaint.glassPanel()` 在已有全屏玻璃底时只绘制透明底色；独立 HUD 底托可调用区域模糊。快捷栏小格使用透明底，不逐格发起模糊。

`FrostedBackdrop` 的 CPU 兜底最多每 2500ms 读回一次，降采样到 160×90 后模糊；拒绝全黑或随机噪点。失败只绘制主题遮罩，不显示占位网格。地图投票和揭晓仍保留地图照片，先绘图再处理玻璃底。

保留 `UiPaint` 和控件原 API，装饰角标、刻度、网格、颗粒等旧入口为空操作；功能性进度条、分隔线和轮盘几何仍可使用。旧数据的 Minecraft 格式码通过 `UiPaint.themed()` 解析，保留粗体等格式并转换颜色；不要在新文案里写颜色码。

## 覆盖范围

部署、职业、地图和阵营选择、揭晓、队伍及密码子页、指挥官相关页面、分数板、结算等均沿用 AUI 交互并统一表面、按钮与文字。补给、FOB、工事、教学、快捷栏、轮盘参数、滚动列表和小队名称输入框也已迁移。完整文件及屏幕清单见 [机器可读核验记录](MINIMAL_GLASS_UI_2026-11-14.json)。

EsRadial 的中心、返回按钮和标签以及 AuraTip 内部绘制属于外部前置；本模组通过开放参数协调样式，并额外以客户端 mixin 替换 EsRadial 0.3.2 硬编码的白色悬停和空白扇区底，统一处理轮盘悬停和空白扇区底。当前指挥轮盘环底已对齐图1的 EsPoints 中性灰配色，见下方动效修订。`com/example/hcrpoints/**` 不编入 Espetro，属于独立 EsPoints 项目。

## 客户端菜单约定

FancyMenu 标题页、加载页与原版菜单配置及素材已打包到 Espetro。启动时在 FancyMenu 读取布局前自动校验并覆盖变化文件，旧文件先备份到实例 `espetro-backups/*-menu-auto-*/`，不覆盖个人选项和运行数据库。详情见 [内置菜单交付说明](UI_FEEDBACK_2026-11-14.md)。标题页左侧全高黑幕向右渐隐，TN 标保留天青色 **`#06DEE5`**。按钮为无边框半透明毛玻璃，元素放在原生按钮后方绘制，避免压暗按钮。

加载页保留实景背景及天青色 TN Logo，**不加渐变黑幕或毛玻璃底托，进度条使用原版**。FancyMenu 配置资源固定暗色，不跟随 `/esui theme`；模组内 UI 支持亮暗切换。

## 启动入口注意

不要对 FancyMenu 主类添加安装器 mixin：该类可能在 Mixin 配置准备前已被第三方提前加载。当前使用已有 `EspetroMixinPlugin.onLoad()` 的 CLIENT 分支安装纯文件菜单，客户端初始化仅做幂等重试。修复已通过生产实例离线启动，资源重载和标题页注册成功；当前产物见 [启动修复记录](UI_STARTUP_FIX_2026-11-14.md)。

## 指挥官排版和插值动效修订

仅指挥官投票主体扩大，候选固定四列、按左到右和上到下排列。按钮按玩家名称、票数和状态标记测宽，高度仅为一行文字加少量留白；单人只占左上一个按钮，禁止随人数减少把按钮撑成整行大卡片。其它投票保持已有居中布局。已选职业图标用原图满亮度显示，不能对完整RGB素材乘深墨色。

AuiScreen 已移除全屏黑幕过渡，背景正常绘制，仅前景树淡出180ms/淡入220ms。UiForegroundLayer 过渡期间将同帧背景与正常前景结果合成，不改变背景亮度；常态直接绘制。UiMotion 使用单调时间逐帧采样 ease-out cubic，禁止恢复为每tick改一次透明度。相同目标不重启动效，改目标从当前值衔接。共享按钮/图像按钮/Chip 的悬停底色160ms、选择180ms缓动，禁用和主题切换立即同步。

两个指挥入口原来保留不同 fallback.ringColors，现在统一到图1已有中性灰 `#B824292B → #C832383A`，不改键位、半径或操作行为。当前构建、备份和验证见 [本轮交付记录](UI_MOTION_2026-11-14.md)。

当前客户端9张编制图、4张地图图已内置，启动时按独立清单同步到原 `EsFactions/`、`EsWorld/` 目录，变化文件先备份；不修改JSON配置或世界数据。最新紧凑四列按钮与图片同步已通过真实离线客户端检查，见 [图片与按钮交付记录](PREVIEW_BUNDLE_COMMANDER_2026-11-14.md)。
