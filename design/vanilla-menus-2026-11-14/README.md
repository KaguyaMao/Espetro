# 原版菜单毛玻璃样式 · 2026-11-14

客户端：`D:\minecraft\squadMC预发布测试\versions\Squad预发布测试`。

扩展到 74 个原版菜单（含 Realms），并覆盖 Forge 模组列表与两个 Embeddium 视频设置入口的背景及原生控件。
包括暂停、选项、声音、控制、按键绑定、语言、聊天选项、资源包、辅助功能、皮肤、在线选项、
世界选择/创建/编辑/规则、服务器列表/直连/编辑、安全提示、断线、进度、统计及确认窗口等。
`进度` 此处指游戏成就菜单（Advancements），不是加载进度条。

使用限定到每个屏幕的 FancyMenu 原生按钮与滑块模板，不设置全局皮肤：
无边框、半透明暖白底色、悬停提亮、禁用减弱；滑块保留原生数值、滑动手柄和输入行为。
所有 `template_apply_width/height/posx/posy/opacity/visibility/label` 均为 false，保留原生布局、文字、可见性与启用逻辑。
模板不注册额外的可点击控件，动作列表为空，保留原有按钮回调、键盘导航和 tooltip。
原生输入框、页签、列表条目仍沿用各自绘制；Embeddium 自绘控件不属于 FancyMenu 原生按钮模板范围。

每个屏幕生成两个互斥布局，用安装版 FancyMenu 的 `IsWorldLoadedRequirement` 区分世界状态：
未进入世界时使用既有实景轮播，进入世界后保留当前世界画面。
背景用 FancyMenu 原生矩形实时模糊（4.0）加暗色透明底；不再逐按钮复制大批模糊图形，单页一个模糊区域。
世界/菜单条件、模板类型、注册屏幕标识、列表背景字段均根据已安装 FancyMenu 3.9.9 字节码确认。
仅注册已验证实际存在、继承 Screen 且非抽象的类。
安装版本将 `key_binds_screen` 错映射为 `KeyBindsList`，此处以真正 `KeyBindsScreen` 类名作为标识。

标题页、加载页文件及其 Logo、TN 天青色、原版加载进度条均保持不变。
聊天输入、背包/容器、游戏 HUD 和其他模组游戏界面不注册此菜单背景。
没有修改 FancyMenu 全局选项、mod jar、服务器地址、开场视频或声音。

## 构建、验证和部署

`build_menus.py` 从本机 Forge 1.20.1 / 47.4.22 类文件验证继承关系，再生成 77 个入口的 154 份配置。
`verify_menus.py` 检查实际输出：两个世界状态的互斥条件、背景层级、纹理、透明度、模板不改原生几何/标签/动作、
控件纹理无边框、加载页与标题页哈希未变、配置 UTF-8 无 BOM。
原生几何未被接管，因此分辨率与语言变化仍由 Minecraft 自身布局处理，背景随屏幕拉伸。
`选项菜单_样式示意.png` 与 `暂停菜单_样式示意.png` 是坐标示意，字体和模糊算法以离线绘制近似，并非实机截图。
当前没有运行中的 Java/Minecraft 进程，未做逐屏实机核验；重启客户端读取新增菜单注册。

`deploy_menus.py` 先备份原注册表和主菜单/加载页，再安装新增资源、布局，最后更新菜单注册。
`deployment.json` 记录部署和备份路径；备份目录的 `restore.ps1` 恢复原注册并禁用本次新增布局，不删除资源。
验证后没有修改已有菜单动作或写入存档。
